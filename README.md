# Форма

Дневник еды, движения и веса. Один пользователь — Дмитрий. Веб-приложение, которое ставится на Samsung Galaxy S23 как обычное приложение (PWA).

Работает сразу локально. Облако (телефон + компьютер) подключается бесплатно через Supabase и Vercel.

## Что внутри

- Поиск продуктов с подсказками: «крупа» → гречневая, рисовая, овсяная…
- У крупы и макарон две карточки: **сухая** и **варёная**, с разными ккал
- Граммовка, КБЖУ, избранное, недавние
- Магазинные пачки с фото через бесплатный Open Food Facts
- Активности: покос, древесина, эллипсоид, программирование, репетиторство
- Вес, график, цель, калории по Mifflin–St Jeor
- Тёмная тема под AMOLED, вёрстка под S23

Без ключей приложение уже ведёт дневник на устройстве. Ключи нужны только чтобы данные не потерялись и открывались с другого экрана.

## Запуск на компьютере

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Открой адрес из терминала (обычно `http://localhost:5173`) в Chrome.

## Облако и хостинг — бесплатно

Три аккаунта: GitHub, Supabase, Vercel. Карта не нужна.

### 1. GitHub

Создай репозиторий и залей этот проект.

### 2. Supabase

1. Зайди на [supabase.com](https://supabase.com) → New project.
2. SQL Editor → вставь содержимое [`supabase/schema.sql`](supabase/schema.sql) → Run.
3. Authentication → Providers → Email включён.
4. Authentication → Providers → Email: выключи **Confirm email**, чтобы сразу войти без письма.
5. Settings → API: скопируй **Project URL** и **anon public** ключ.

В корне проекта:

```bash
copy .env.example .env
```

Вставь URL и ключ в `.env`.

На Vercel те же переменные: `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.

### 3. Vercel

1. [vercel.com](https://vercel.com) → Import GitHub-репозитория.
2. Framework: Vite.
3. Environment Variables — две строки выше.
4. Deploy. Получишь ссылку вида `https://forma.vercel.app`.

Первый вход в приложении: «Создать аккаунт» со своей почтой. Это единственный пользователь.

### 4. Чтобы база не засыпала

Бесплатный Supabase засыпает через 7 дней без запросов. Если пользуешься каждый день — не заснется. На всякий случай:

GitHub → Settings → Secrets and variables → Actions:

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

Файл [`.github/workflows/keep-alive.yml`](.github/workflows/keep-alive.yml) раз в сутки пингует базу.

## Поставить на Galaxy S23

1. Открой ссылку Vercel в **Chrome**.
2. Меню ⋮ → **Добавить на главный экран**.
3. Иконка «Форма» появится рядом с обычными приложениями.
4. Открывается на весь экран, без адресной строки.

## Без облака

Можно пользоваться после `npm run dev` или после выкладки статики. Данные живут в браузере. Для телефона и компьютера одновременно всё же лучше подключить Supabase.
